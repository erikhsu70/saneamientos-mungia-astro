# Instrucciones del proyecto

Para cualquier tarea de investigación, redacción, actualización, maquetación, enlazado, preview o publicación de artículos del blog de Saneamientos Mungia, lee y aplica íntegramente:

- `skills/saneamientos-blog-editor/SKILL.md`
- `skills/saneamientos-blog-editor/references/feedback-log.md`

Después de recibir nuevo feedback editorial explícito del usuario:

1. Aplica la corrección al artículo actual.
2. Añade el aprendizaje al registro de feedback.
3. Actualiza las reglas operativas solo si el aprendizaje debe afectar a artículos futuros.
4. Evita convertir ejemplos aislados en una plantilla rígida.
